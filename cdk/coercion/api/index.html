coerceStringArray(value: any, separator: string | RegExp) => string[]

Coerces a value to an array of trimmed non-empty strings. Any input that is not an array, null or undefined will be turned into a string via toString() and subsequently split with the given separator. null and undefined will result in an empty array. This results in the following outcomes: - null -> [] - [null] -> ["null"] - ["a", "b ", " "] -> ["a", "b"] - [1, [2, 3]] -> ["1", "2,3"] - [{ a: 0 }] -> ["[object Object]"] - { a: 0 } -> ["[object", "Object]"]

Details

Useful for defining CSS classes or table columns.
