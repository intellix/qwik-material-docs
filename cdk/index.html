CDK

The ported `@angular-community/qwik-cdk` entry points — unstyled behavior primitives that qwik-material's components build on, usable directly in your own components too.

Accessibility (a11y)Focus trapping, focus monitoring, live announcements, and high-contrast detection.AccordionFoundation state for a set of expandable/collapsible panels.BidiResolves and observes the current text layout direction (LTR/RTL).ClipboardCopies text to the clipboard, including a directive hook for a copy-trigger element.CoercionSmall helpers for normalizing boolean/number/array/CSS-pixel inputs.CollectionsSingle/multiple selection state, plus a DataSource abstraction for array-rendering components.DialogA low-level, unstyled modal dialog service that Material Dialog builds on.KeycodesNamed keyboard-event key constants and key-combination helpers.LayoutObserves CSS media-query breakpoints reactively.OverlayA configurable service for opening floating panels, positioned relative to an origin.PlatformRuntime platform/browser-engine detection (SSR-safe).PortalRenders content into a different part of the DOM than where it was declared, including attaching into an arbitrary external DOM node while keeping Qwik context intact.ScrollingTracks registered scrollable elements and reports viewport size/scroll-position changes.StepperFoundation linear/non-linear step-sequence state, used by Material Stepper.TableA headless, high-performance data-table core that Material Table builds on.Text fieldAutosizing textarea and real browser-autofill detection for text inputs.TreeA headless hierarchical-data renderer that Material Tree builds on.

qwik-material — a Qwik port of Angular Material. Not affiliated with or endorsed by Google.
