Hooks

useMatChipsProvider: (config?: MatChipsConfig) => void

Provides {@link MAT_CHIPS_CONFIG} for this subtree — call once near the root (or anywhere deeper, to override just that part of the tree) so every MatChip family component descendant resolves its defaults from config instead of its own hardcoded fallback. Only this one context is provided; every other qwik-material configuration context stays whatever an ancestor (or nothing) already provided — see README.md's "Configuring the library" section.

useMatChipsStyles: () => void

Registers this entry point's CSS — scss/chips/chips-prebuilt.scss, compiled inside @layer qwik-material — for the rendering document, once: upstream's MatChipSet/MatChipListbox/MatChipGrid's styleUrl: 'chip-set.css' and MatChip/MatChipOption/MatChipRow's 'chip.css' (chip*.ts) (src/material/chips/), attached when the component is first created, unscoped (ViewEncapsulation.None). Server rendering writes it before the first instance; a component first rendered in the browser brings it with its own chunk. Call it as the component's FIRST hook — Qwik keys a useStyles$ <style> by the call site AND the hook's index in the component, so only first-hook calls share one <style> (README "Component styles"). Exported for markup rendered without the component (a hand-written host, a plain render function).
