Components

All 35 ported qwik-material components, grouped the same way as material.angular.dev.

Form Controls

AutocompleteSuggests options as the user types into a text input.CheckboxA checked/unchecked/indeterminate selection control, Material Design styled.ChipsCompact elements for input, attributes, or actions, as a set.DatepickerA calendar-backed input for picking a single date.Form FieldWraps a form control (input, select, …) with a floating label, hints, and errors.InputThe native <input>/<textarea> control used inside <MatFormField>.Radio ButtonA single selection from a set of mutually exclusive options.SelectA Material-styled dropdown select control, usable inside a <MatFormField>.Slide ToggleAn on/off control, like a switch.SliderLets the user select a value (or range) from a given range by dragging a thumb.TimepickerA dropdown-backed input for picking a time of day.

Navigation

MenuA floating panel of choices, opened from a trigger element.SidenavA collapsible side content area, next to or over the main content.StepperGuides a user through a sequence of numbered steps.TabsOrganizes content into separate views, one visible at a time.ToolbarA container for a page's or section's title, navigation, and actions.

Layout

CardA styled content container with header, image, actions, and footer sections.DividerA thin line that groups content into sections.Expansion PanelAn expandable panel, and an accordion of several panels.Grid ListA 2-dimensional grid layout of tiles.ListPresents rows of items, including navigation and action lists.TreeA hierarchical list, flat or nested, with optional expand/collapse.

Buttons & Indicators

BadgeA small status descriptor overlaid on another element, like an icon or button.ButtonNative button and anchor elements enhanced with Material Design styling.Button ToggleOn/off and single/multiple selection of a set of button-shaped options.IconRenders an icon from an icon font, ligature, SVG, or custom icon set.Progress BarA horizontal bar showing the progress of an operation, determinate or not.Progress SpinnerA circular spinner showing the progress of an operation, determinate or not.

Popups & Modals

Bottom SheetA panel that slides up from the bottom edge of the screen.DialogA modal overlay that blocks interaction with the rest of the page.Snack BarA brief, transient message displayed at the edge of the screen.TooltipA short, descriptive label shown on hover, focus, or long-press.

Data Table

PaginatorControls for paging through a collection of data.Sort HeaderAdds sortable column headers to a table.TableA data table with sorting, pagination, and row selection, built on the CDK table.
