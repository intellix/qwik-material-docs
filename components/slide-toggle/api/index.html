Hooks

useMatSlideToggleProvider: (config?: MatSlideToggleConfig) => void

Provides {@link MAT_SLIDE_TOGGLE_CONFIG} for this subtree — call once near the root (or anywhere deeper, to override just that part of the tree) so every MatSlideToggle descendant resolves its defaults from config instead of its own hardcoded fallback. Only this one context is provided; every other qwik-material configuration context stays whatever an ancestor (or nothing) already provided — see README.md's "Configuring the library" section.

Types

MatSlideToggleConfig

Defaults applied to every MatSlideToggle in a subtree. Consumers provide this via useMatSlideToggleProvider(...). Mirrors upstream's MatSlideToggleDefaultOptions (src/material/slide-toggle/slide-toggle-config.ts).

NameTypeDescription
disableToggleValue?booleanWhether a click toggles the checked value.
Details

When true, clicking still fires onToggleChange$ but never onChange$/flips the rendered state — mirrors upstream's disableToggleValue, which has no per-instance @Input() of its own (provider-only, same as here).

color?stringDefault theme color. This API is supported in M2 themes only; it has no effect in M3 themes. See upstream's own doc comment on color for the M3 styling guidance.
hideIcon?booleanWhether to hide the icon inside the slide toggle, by default.
disabledInteractive?booleanWhether disabled slide toggles should remain interactive, by default.
