qwik-material

A Qwik port of Angular Material — the same components, the Qwik way.

Get started

High quality

Accessible, well-tested components with the same DOM and visual output as Angular Material — verified against a live parity suite, component by component.

Resumable

Built on Qwik's fine-grained reactivity and resumability — no framework bootstrap before the page is interactive.

Familiar

If you know Angular Material's API, you already know most of qwik-material's — see the migration guide for the concept-by-concept map.
